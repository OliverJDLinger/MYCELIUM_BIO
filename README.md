# MYCELIUM_BIO
Python based simulation model to predict the growth patterns of two medicinal fungi Pleurotus osteatus and Ganoderma lucidum. These fungi when treated act like extracellular matrix of human body tissues.
## Key goals
Predict the structural outcome (branching density, network connectivity, porosity) of mycelial growth under different environmental parameters to identify conditions that produce stable, skin-like matrices.

Simulates hyphal tip extension, branching, and anastomosis (fusion).

Tracks nutrient diffusion and uptake.

Outputs structural metrics: fractal dimension, connectivity, and porosity.
