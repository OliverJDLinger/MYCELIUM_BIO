# Cell Regeneration with the help of mycelial organic structures, and processes 
## Intro
This section is dedicated in modelling the human body that has a symbiotic relationship iwth an internal mycelial network.
Both work to maintain, repair and replace cells and tissues. 
Caveats **Mycelium must not disrupt human function, it must aid in cell growth, cancer rate reduction and overall efficency, and offer new structures to compensate for human failures.**

### Description
Using the mycelial network as a natural scaffold, can human cells be grown around it, and if so can this scaffold be permanently deployed in the human body for accelerated growth?
